# Sanctum Design System

## Product Feeling

Sanctum should feel like entering a digital home, not opening another app.

Users should feel:
- welcomed
- curious
- safe
- inspired
- connected

## Brand Promise

Sanctum helps creators build Worlds their communities can truly belong to.

## Core Motto

Build Belonging.

## Visual Direction

Sanctum should feel:
- atmospheric
- warm
- elegant
- immersive
- modern
- slightly magical

Not corporate.  
Not childish.  
Not plain SaaS dashboard.

## Primary Experience

A visitor should not land on login first.

They should land on a beautiful public page that explains:

1. What Sanctum is
2. Why it matters
3. How creators use it
4. How to enter or create a World

## Main Colors

Base background:
- Deep midnight navy / near black

Surface cards:
- Dark blue-gray

Accent colors:
- Soft gold
- Violet
- Cosmic blue
- Warm white

## UI Style

Use:
- rounded cards
- soft shadows
- gentle gradients
- large hero sections
- calm spacing
- subtle animation
- clean forms

Avoid:
- clutter
- harsh colors
- overly corporate layouts
- too many buttons
- generic dashboard vibes

## Page Priority

The first pages to redesign are:

1. Landing Page `/`
2. Login Page `/login`
3. Register Page `/register`
4. Creator World Page `/world/:slug`
5. Creator Hub `/hub`

## Route Philosophy

`/` = public landing page  
`/login` = login  
`/register` = create account  
`/world/:slug` = public creator World  
`/hub` = creator management area  

## Design Principle

Every screen should answer:

“Does this help someone feel like they are entering, creating, or returning home?”

If not, simplify it.
